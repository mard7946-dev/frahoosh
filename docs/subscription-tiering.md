# Subscription tiering

Frahoosh currently defines these student-count tiers: 1–100, 101–200, 201–300, 301–500, 501–700, and 701–1000 students. Each tier is available for 1, 2, 3, 6, 9, 12, or 24 months.

Plan prices intentionally remain unset until the platform owner enters the actual prices in the subscription-plan module. An active subscription cannot be created from a zero-price plan. The database fills the purchased duration and capacity from the selected plan, rejects a plan below the school's current enrollment count, enforces the student limit, and blocks operational data writes after expiry while retaining the school's records.

Android production distribution requires a persistent release keystore. Without the configured signing secrets, the build workflow deliberately produces only a debug-signed test APK and does not publish it to the stable public download branch.
